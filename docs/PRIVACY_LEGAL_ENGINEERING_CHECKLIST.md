# Privacy and Legal Engineering Checklist

This is an engineering inventory, not legal advice. Items requiring counsel or provider confirmation are marked **UNVERIFIED**.

## Current data

- Local: onboarding preferences, watchlist/order, groups, thesis text, snapshots, seen changes, saved REAL brief history, and a random installation ID.
- Server analytics: allowlisted event name, bounded allowlisted properties, random installation ID, and event time.
- Server feedback: response hash, task, bounded symbols, helpful flag, structured reason, random installation ID, and time.
- Provider/AI caches: normalized evidence, request/evidence hashes, validated response, source metadata, and cache times.
- Explicitly excluded: raw Ask text from telemetry, full thesis text from telemetry, article bodies, invasive device fingerprints, credentials.
