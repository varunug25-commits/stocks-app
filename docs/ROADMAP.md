# MarketBrief Roadmap

## Complete

- Phase 1: Expo foundation, dark design system, reusable finance cards, and polished mock Today feed.
- Phase 2 Milestone 1: mock authentication, seven-step onboarding, local preferences, tests, and device-size evidence.

## Recommended next milestone

Phase 2 Milestone 2: five-tab navigation cleanup, Today refinement, Markets discovery, search, and market-state surfaces using local mock data.

## Later

Watchlist, Stock Details, Briefs, Alerts, Profile, Paywall, and Legal shell work come only after Milestone 2 is stable. Backend, real authentication, APIs, AI, payments, and push infrastructure remain deferred until the complete mobile design shell is approved.
