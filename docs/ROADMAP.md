# MarketBrief Roadmap

## Complete

- Phase 1: Expo foundation, dark design system, reusable finance cards, and polished mock Today feed.
- Phase 2 Milestone 1: mock authentication, seven-step onboarding, local preferences, tests, and device-size evidence.
- Phase 2 Milestone 2: five-tab discovery shell, personalized Today, Markets, Search, Watchlist preview, Briefs preview, and Profile.

## Recommended next milestone

Phase 2 Milestone 4: generated Morning/Evening Briefs using local mock content only.

## Later

Complete Briefs, Alerts, Paywall, and Legal shell work follow Milestone 3 review. Backend, real authentication, APIs, AI, payments, and push infrastructure remain deferred until the complete mobile design shell is approved.

## Current status

- Phase 2 Milestone 2: approved and merged through PR #1 after real-device Android smoke testing.
- Milestone 3: implemented on its feature branch and awaiting review — full local stock detail, charts, evidence explanation, enhanced search, and persistent watchlist management.
- Milestone 4: deferred — generated Morning/Evening Briefs.

Live services, backend authentication, alerts, subscriptions, payments, and brokerage features remain outside the stable design-shell phase.
