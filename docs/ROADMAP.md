# MarketBrief Roadmap

## Complete

- Phase 1: Expo foundation, dark design system, reusable finance cards, and polished mock Today feed.
- Phase 2 Milestone 1: mock authentication, seven-step onboarding, local preferences, tests, and device-size evidence.

## Recommended next milestone

Phase 2 Milestone 3, after Milestone 2 approval: full stock details, charts, and richer local watchlist management.

## Later

Full Stock Details, complete Briefs, Alerts, Paywall, and Legal shell work come only after Milestone 2 is stable. Backend, real authentication, APIs, AI, payments, and push infrastructure remain deferred until the complete mobile design shell is approved.

## Current status

- Phase 2 Milestone 2: implemented and awaiting review in draft PR #1.
- Milestone 3: deferred — full stock detail, charts, richer watchlist management, and related flows.
- Milestone 4: deferred — generated Morning/Evening Briefs.

Live services, backend authentication, alerts, subscriptions, payments, and brokerage features remain outside the stable design-shell phase.
